01 — Building blocks

Six ideas cover most of the framework.

Everything above — the boxes, the arrows, the diamond — maps to one of these primitives.

State

A typed object (TypedDict / Pydantic model) that flows through every node. Each field can define its own merge behavior via a reducer.

Node

A Python function that receives the current state and returns a partial update. Can call an LLM, a tool, or plain logic.

Edge

A fixed connection: after node A finishes, node B always runs next. No decision involved.

Conditional edge

A routing function inspects the state at runtime and picks the next node — this is what makes branches and loops possible.

Checkpointer

Persists state after every step, keyed by a thread_id — enabling resumability, multi-turn memory, and time travel.

Interrupt

Pauses execution at a chosen node so a human can review or edit state before the graph resumes — human-in-the-loop.

02 — What a chain can't do

Cycles are ordinary in a graph.

A plain chain runs forward once. If retrieve comes back empty, a chain has no way to try again — it just continues with nothing.

In LangGraph, the conditional edge after enough? can route straight back to retrieve, and the loop continues until the routing function is satisfied.

03 — When to reach for which

Chain vs. graph, side by side.

Chain

prompt→ model→ parser
  • ·Fixed, linear sequence decided at build time
  • ·No native cycles or branching
  • ·No built-in persistence between runs
  • ·Simple to read, simple to debug
  • ·Best for predictable, single-pass pipelines

Graph

retrieve→ enough?↻ / → generate
  • ✓Routing decided at runtime by state
  • ✓Native cycles, branches, and rejoins
  • ✓Checkpointed state — resumable, replayable
  • ✓Supports pausing for human review
  • ✓Best for agentic, iterative, multi-agent work

# define state, nodes, and routing from langgraph.graph import StateGraph, START, END def should_continue(state): if len(state["documents"]) == 0: return "retrieve" # loop back return "generate" graph = StateGraph(AgentState) graph.add_node("retrieve", retrieve) graph.add_node("generate", generate) graph.add_edge(START, "retrieve") graph.add_conditional_edges("retrieve", should_continue, {"retrieve": "retrieve", "generate": "generate"}) graph.add_edge("generate", END) app = graph.compile()
